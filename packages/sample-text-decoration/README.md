# Text Decoration

Select text in [the playground](https://lvce-editor.github.io/extension-samples/text-decoration/), press F1, and run **Sample: Underline Selection**. A red, straight 2-pixel underline appears without changing the text or its undo history. Select across lines or add another overlapping range to underline more text. An empty selection does nothing and repeating a range does not add duplicates.

Run **Sample: Clear Underlines** to clear the provider output, or **Sample: Dispose Underlines** to unregister the provider. After disposal, rebuild or reset the sample to register it again. Underlines follow text when edits happen before them, including inserted or deleted lines. Edits that touch an underlined range clear that range to avoid underlining unrelated text. Insertions at a range's start move it with the following text; insertions at its end remain outside it. Edit the source and save with Ctrl+S to rebuild; the playground refreshes the provider after reloading and removes stale underlines.

`registerEditorTextDecorationProvider` receives the current document text and normalized selections. It returns ranges using zero-based UTF-16 row/column coordinates and an exclusive end, with a six-digit hexadecimal `color` and optional `thickness` (1–4 pixels). The editor queries providers after document edits. `refreshEditorTextDecorations()` explicitly replaces the active editor's results after commands change provider state. Returning `[]` clears output; disposing and refreshing removes the registration's output. Built-in links, diagnostic squiggles, line decorations and gutter decorations remain independent.
