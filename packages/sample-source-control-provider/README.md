# Source Control Provider Sample

Registers a source control provider with a mock changes group, SVG decoration icons, commit-message generation, and example add, discard, and commit handlers. Use the Discard action on a changed file to remove that file from the in-memory changes list.

The sample uses in-memory data rather than a Git repository. Edit `extension.json`, `icons/modified.svg`, or the provider source and save to update the preview.
